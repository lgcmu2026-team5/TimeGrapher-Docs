## Task 2 — 24시간 내 `main` 커밋 · ✅ 완료

5라운드(Claude 3렌즈 workflow ×5 + 매 라운드 codex ×3 + codex 합의 3회). High/Medium 추이 **8 → 4 → 1 → 1 → 0**. **5라운드: codex 3개 모두 H0/M0/L0, workflow는 범위 밖 Low 1건뿐.** 게이트(High/Medium 없음) 충족.

### 확정 High/Medium — 전부 수정 (10개 커밋, `d15f53f`…`82d7b18`)
| 영역 | 무엇이 문제였고 → 무엇이 개선됐는가 |
|------|--------------------------------------|
| 파형 진폭 | 레인 라벨이 소각 선형 근사를 써서 저진폭에서 다른 판독과 발산 → 표준 `WatchMetrics.Amplitude` 사용, **`<360°` 유효성 캡**까지 적용해 다른 판독과 동일하게 `—` 표시 |
| 파형 커서 | toc 비트에서 커서가 **tic** 반쪽에 찍히고, 렌더 클립 밖 스크럽도 허용 → toc 오프셋만큼 이동 **+** 렌더 클립으로 바운드 |
| 파형 페어링 | **비트 누락** 시 같은 위상 두 캡처가 오페어링(잘못된 반쪽/오라벨) → 순수 `AssignPairHalves`로 각 세그먼트를 실제 반쪽에 배정 |
| 파형 오버레이 | 그 뒤에도 mean-C 가이드·커서가 숨겨진 중복을 참조 → 새 `VisibleSegments`로 **그려진 집합**만 mean-C/가이드/커서에 공급 |
| 필터 스코프 | 라이브 X 범위를 낡은/빈 데이터로 계산 → 현재 프레임으로 계산(1프레임 지연·리셋 직후 빈 화면 제거) |
| 포지션 | 수직 포지션 없이도 "OK" 판정 가능, 미측정 포지션에서 불균형 배너 점등 → 판정이 수직≥2 + 수평≥1 강제, 불균형은 자격(30비트↑) 포지션으로 게이트 |
| 스코프 스윕 | 툴바는 "2×" 활성인데 실제 1× 렌더 → 뷰모델 기본값을 프로젝터 기본값(1×)에 맞춤 |
| 시뮬레이션 | 이전 레이트와 다른 선택 레이트가 무시됨 → `SetAudioRate(selection.SampleRate)`(재생 경로와 동일) |
| 스펙트로그램 | 최종 플러시 프레임이 락된 비트 주기를 누락 → 동결된 "Last Beat" 뷰가 올바른 타이밍 유지 |

### Low — 수정함 (사소 + 정확성)
- 설정: `UseCOnset` 토글 라벨을 "**timing**"으로 정정(+ 테스트).
- 미사용 상수 제거(`PeakOffsetMs`, `LaneLabelPeakOffsetMs`, `LaneLabelYOffset`).
- `WatchPosition` 45° 멤버 주석을 새 크라운 대각 명칭에 맞게 정정.

### 제기됐으나 **수정 안 함** (codex와 합의)
| 항목 | 처리 |
|------|------|
| 윈도우 캡처가 **엔드포인트 모호** 시 레이트 미반환 | **기각** — 의도된 안전 게이트(SAP sanity checking). fallback 추가는 의도적 강화를 되돌리고 AGENTS.md "요청 없으면 fallback 금지" 위반 |
| LongTerm accept 밴드가 `VerticalSpan` 사용 | **기각** — 오탐. `VerticalSpan`이 Y 코리도를 올바르게 음영 처리 |
| 테마 토글 후 SoundPrint 프레임 dedup | **Low로 강등** — 일시적·자가 복구·색상 정상 |

### 미수정 **Low** (범위상 그대로 둠)
- **리눅스 장치 선택 시 UI ~0.75초 블로킹**(동기 probe) — 보류: 수정이 UI 스레드 분리/스레딩 리팩터라 AGENTS.md "요청 없으면 성능/구조 리팩터 금지" 범위 밖.
- **Help 버튼** `Process.Start`에 Linux/Pi용 try/catch 없음 — 보류: AGENTS.md "요청 없으면 예외처리 금지".
- **스펙트로그램 `RebuildView`**가 매 렌더 전체 창 재구성 — 보류: 성능 리팩터, 범위 밖.
- `manual/graphs/positions.html`이 불균형 임계 **25 s/d**라 적었으나 코드는 **15 s/d** — **24시간 범위 밖**(매뉴얼은 윈도우에 미포함).
- `manual/controls.html`이 **384 kHz**를 선택 가능 레이트로 표기하나 표준 레이트에서 제거됨 — **24시간 범위 밖**(윈도우 이전 커밋).

## 1) 핵심 근거 요약

- **G09 스펙트로그램**: 드래프트는 "가장 최근 비트 또는 선택한 시간 창 조사", "반복 에너지 구조 관찰", "비트 간 비교"를 권장. 현재는 롤링 STFT + 일시정지 + dB 범례까지 구현되어 표시 자체는 충실하나, *비트 단위 선택·비교 보조기능*이 빠져 있음.
- **G10 파형 비교**: 드래프트는 "비트 간 구조 변화 조사", "각도/시간 기준 참조 마커"를 명시. 현재는 정렬 레인·가이드·헤더 수치·엔벨로프까지 구현. 구조 변화의 *명시적 시각화*와 *각도 기준 마커*가 미구현.
- **G11 스코프 스윕**: 드래프트는 "상반부와 하반부를 결합한 처리 신호"와 "공칭 진동수 등 최근 측정 참조값"을 명시. 현재는 정류 폴딩·드리프트 동기화·rate/amp/beat-error readout까지 구현. 상/하반파 결합 표현과 공칭 진동수(BPH) 사용자 표시가 보강 대상.
- **G12 다중 필터**: 16개 항목 전부 구현 확인. 수정 대상 없음.

## 3) 실행 순서 제안

1. **G10 FR-10-11** (권장·🔴) — 비트 간 구조 변화 시각화: 진단 가치가 가장 크므로 우선.
2. **G09 FR-09-03/04/05** (권장·🟡) — 스펙트로그램 비트 선택/비교 보조: 일시정지 커서 → 비트 경계 마커 순으로.
3. **G11 FR-11-02** (권장·🟡) — 상/하반파 결합 표현: 기존 MIRROR 로직 재사용.
4. **선택 등급 정리** — FR-11-08(공칭 진동수 표시), FR-10-14(각도 마커), FR-10-12(분해 연계)는 보유 데이터 노출/연계 수준의 경량 작업으로 마무리.

> G12는 전 항목 🟢이므로 별도 수정 작업 없음(회귀 방지용 테스트 유지만 권장).

## 4) 체크리스트 반영 가이드

- 구현 반영 전: 🔴/🟡 유지 + "수정 전략" 문구 추가
- 구현/테스트 완료 후: 🟢로 전환하고 근거 파일/테스트 케이스를 함께 기입
- 선택(optional) 등급 항목은 미구현이어도 평가상 감점 요인이 아닐 수 있으므로, "선택 등급 — 보유 데이터로 경량 구현 가능"임을 근거란에 명시

|---|---|---|---|
| FR-09-01 | mandatory | 시간-주파수 스펙트로그램 디스플레이는 시계의 음향 에너지가 시간과 주파수에 걸쳐 어떻게 분포되어 있는지를 보여주는 시간-주파수 스펙트로그램을 사용자에게 제공해야 한다. | 🟢 SpectrogramFrameProjector(STFT)·SpectrogramRenderer 구현 확인 |
| FR-09-02 | mandatory | 시간-주파수 스펙트로그램 디스플레이는 가로축을 시간, 세로축을 주파수로 하고 신호 강도를 색상 강도로 표현하여 스펙트로그램을 사용자에게 제공해야 한다. | 🟢 x=시간, y=주파수(저주파 하단), 색상=dB. 주파수축 라벨 표시 확인 |
| FR-09-03 | recommended | 시간-주파수 스펙트로그램 디스플레이는 가장 최근의 비트 또는 선택한 최근 시간 창(time window)을 조사할 수 있는 기능을 사용자에게 제공하는 것이 권장된다. | 🟡 일시정지(pause)로 약 10초 롤링 윈도우 정지 검사 가능. 단, 특정 비트 선택 기능은 없음 |
| FR-09-04 | recommended | 시간-주파수 스펙트로그램 디스플레이는 특성 주파수 범위에서 반복되는 에너지 구조를 볼 수 있는 기능을 사용자에게 제공하는 것이 권장된다. | 🟡 롤링 스펙트로그램으로 반복 에너지 구조가 시각적으로 보이나, 식별/강조(주파수 대역 하이라이트) 보조기능은 없음 |
| FR-09-05 | recommended | 시간-주파수 스펙트로그램 디스플레이는 하나의 비트와 다음 비트를 비교할 수 있는 기능을 사용자에게 제공하는 것이 권장된다. | 🟡 연속 비트가 인접 컬럼으로 표시되어 육안 비교는 가능하나, 비트 단위 분할·나란히 비교 전용 UI는 없음 |
| FR-09-06 | recommended | 시간-주파수 스펙트로그램 디스플레이는 상대적인 신호 강도를 해석할 수 있는 색상 스케일 또는 범례를 사용자에게 제공하는 것이 권장된다. | 🟢 inferno 계열 64색 그래디언트 범례(-80~0 dB) 구현 확인 |

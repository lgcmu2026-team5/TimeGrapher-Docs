# ADR 007: Enforce Dependency Boundaries with a CI Fitness Function

ADR 002의 의존 규칙(Core 무의존, 하향 단방향)은 문서·리뷰만으로는 침식된다. Core에 OS 타입 참조 한 줄이 섞이거나 OS별 publish에 잘못된 DLL이 들어가도 런타임 전까지 드러나지 않는다.

## Decision
핵심 의존 경계를 **CI 적합성 함수(fitness function)**로 강제한다. CI가 `Select-String`(pwsh)으로 Core 안의 `NAudio`/`TimeGrapher.Platform`/`WindowsAudio` 텍스트를 차단하고, OS별 산출물에 잘못된 DLL이 섞이면 빌드를 실패시킨다. 위반은 경고가 아니라 실패하는 테스트다.

## Rationale
* **경계의 구조적 보존**: ADR 002 규칙을 실행 가능한 불변식으로 유지한다.
* **저비용 고효과**: grep 수준 검사로 가장 비싼 계층 역전을 막는다.

## Status
Accepted — `.github/workflows/ci.yml` 상시 실행, SAP `restrict dependencies` ✓.

## Consequences
* 문자열 매칭은 우회·오탐 여지가 있어 금지 토큰 목록 유지보수가 필요하다.
* 경계 강제가 CI에 종속돼 로컬에선 자동 강제되지 않는다.

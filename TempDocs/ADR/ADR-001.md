# ADR 001: Adopt C#/.NET with Avalonia as the Cross-Platform Application Stack

원본 Qt/C++ TimeGrapher를 포팅하며, 동일 소스를 Windows 11(x64)와 Raspberry Pi 5(ARM64)에서 함께 실행해야 한다(C-3). 플랫폼별로 코드를 분기하면 중복 유지보수와 동작 불일치가 생긴다.

## Decision
언어·런타임은 **C#/.NET**, GUI는 크로스 플랫폼 프레임워크 **Avalonia**를 채택한다. OS별 오디오 백엔드(Windows: NAudio/WASAPI, Linux: pw-record/arecord)는 Core가 소유한 인터페이스 뒤에 은닉하고, 빌드 타깃에 따라 플랫폼 참조를 조건부로 바인딩한다(주 배포 타깃은 RPi5).

## Rationale
* **이식성(C-3)**: 단일 코드베이스로 Windows·RPi5를 커버한다.
* **실시간 GUI**: Avalonia GPU 가속 경로를 사용한다. RPi5 렌더링 리스크는 [EXP-01](../../Milestone/ko/4-Planned-Experiments.md) 기술 실험으로 검증한다.

## Status
Accepted

## Consequences
* GC 런타임이므로 비트당 125 ms 마감을 지키려면 무할당 전술이 필요하다(ADR 005).
* OS 차이를 흡수할 계층·어댑터가 필요하다(ADR 002).
* 런타임의 스레드 우선순위 지정은 Linux에서 효과가 없다(ADR 003).

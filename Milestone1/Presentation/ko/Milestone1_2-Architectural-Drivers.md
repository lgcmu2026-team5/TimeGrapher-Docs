# Architectural Drivers

## Functional Requirements
 
### G01 · Watch-Position Testing
| ID | Grade | Requirement |
|----|-------|-------------|
| FR-01-01 | mandatory | 시계 자세 측정 시험은 사용자에게 표준 측정 자세에서 기계식 시계를 테스트할 수 있는 기능을 제공해야 한다. |
| FR-01-02 | mandatory | 시계 자세 측정 시험은 GUI를 통해 사용자에게 현재 시계 자세를 제공해야 한다. |
| FR-01-03 | mandatory | 시계 자세 측정 시험은 수평 자세인 CH 및 CB와 수직 자세인 6H, 9H, 3H, 12H로 구성된 표준 자세 세트를 사용자에게 제공해야 한다. |
| FR-01-04 | desired | 시계 자세 측정 시험은 사용자에게 중간 자세에 대한 지원을 제공해야 한다. |
| FR-01-05 | mandatory | 시계 자세 측정 시험은 측정이 진행되는 동안 활성 측정 자세를 사용자에게 명확하게 표시해 주어야 한다. |
| FR-01-06 | mandatory | 시계 자세 측정 시험은 활성 측정 자세와 관련된 측정 결과를 사용자에게 제공해야 한다. |
 
### G02 · Trace Display
| ID | Grade | Requirement |
|----|-------|-------------|
| FR-02-01 | mandatory | 트레이스 디스플레이는 시간에 따른 일오차(rate deviation) 그래프를 사용자에게 제공해야 한다. |
| FR-02-02 | mandatory | 트레이스 디스플레이는 시간에 따른 진각(amplitude) 그래프를 사용자에게 제공해야 한다. |
| FR-02-03 | mandatory | 트레이스 디스플레이는 일오차와 진각을 세로로 정렬된 단일 그래프 형태로 사용자에게 제공해야 한다. |
| FR-02-04 | mandatory | 트레이스 디스플레이는 일오차와 진각을 두 개의 별도 그래프로 사용자에게 제공해야 한다. |
| FR-02-05 | mandatory | 트레이스 디스플레이는 일오차(s/d) 측정값에 대한 평활화(smoothing) 기능을 사용자에게 제공해야 한다. |
| FR-02-06 | mandatory | 트레이스 디스플레이는 시계가 느려지는 상태를 나타낼 때 사용자에게 알림을 제공해야 한다. |
| FR-02-07 | mandatory | 트레이스 디스플레이는 각 그래프에 대한 설명 텍스트 또는 라벨을 사용자에게 제공해야 한다. |
| FR-02-08 | mandatory | 트레이스 디스플레이는 평균값 및 시간에 따라 업데이트되는 이동 평균값을 사용자에게 제공해야 한다. |
| FR-02-09 | mandatory | 트레이스 디스플레이는 두 측정값(일오차 및 진각)에 대한 장기 요약 정보를 사용자에게 제공해야 한다. |
| FR-02-10 | mandatory | 트레이스 디스플레이는 측정된 진각이 270°–300° 범위를 벗어날 때 사용자에게 경고 알림을 제공해야 한다. |

| FR-03-04 | mandatory | 바리오 디스플레이는 일오차의 평균값을 사용자에게 제공해야 한다. |
| FR-03-05 | mandatory | 바리오 디스플레이는 일오차의 표준편차를 사용자에게 제공해야 한다. |
| FR-03-06 | mandatory | 바리오 디스플레이는 일오차의 경과된 측정 시간을 사용자에게 제공해야 한다. |
| FR-03-07 | mandatory | 바리오 디스플레이는 일오차의 현재 값을 사용자에게 제공해야 한다. |
| FR-03-08 | mandatory | 바리오 디스플레이는 진각의 최솟값을 사용자에게 제공해야 한다. |
| FR-03-09 | mandatory | 바리오 디스플레이는 진각의 최댓값을 사용자에게 제공해야 한다. |
| FR-03-10 | mandatory | 바리오 디스플레이는 진각의 평균값을 사용자에게 제공해야 한다. |
| FR-03-11 | optional | 바리오 디스플레이는 진각의 표준편차를 사용자에게 제공해야 한다. |
| FR-03-12 | mandatory | 바리오 디스플레이는 진각의 경과된 측정 시간을 사용자에게 제공해야 한다. |
| FR-03-13 | mandatory | 바리오 디스플레이는 진각의 현재 값을 사용자에게 제공해야 한다. |
| FR-03-14 | mandatory | 바리오 디스플레이는 그래프 상에 녹색 영역(green zone)으로 표시되는 각 측정 항목의 허용 가능한 최소-최대 범위를 사용자에게 제공해야 한다. |
| FR-03-15 | mandatory | 바리오 디스플레이는 그래프 상에 파란색 화살표로 표시되는 각 측정 항목의 최소/최대 값을 사용자에게 제공해야 한다. |
| FR-03-16 | mandatory | 바리오 디스플레이는 그래프 상에 빨간색 화살표로 표시되는 각 측정 항목의 평균값을 사용자에게 제공해야 한다. |
| FR-03-17 | optional | 바리오 디스플레이는 각 측정 항목의 최대-최소 차이를 사용자에게 제공해야 한다. |
 
### G04 · Multi-Position Sequence Display
| ID | Grade | Requirement |
|----|-------|-------------|
| FR-04-01 | mandatory | 다자세 시퀀스 디스플레이는 GUI 내에 시퀀스 표시 화면을 사용자에게 제공해야 한다. |
| FR-04-02 | mandatory | 다자세 시퀀스 디스플레이는 여러 시계 테스트 자세에 걸친 완전한 측정 사이클을 사용자에게 제공해야 한다. |
| FR-04-03 | mandatory | 다자세 시퀀스 디스플레이는 단일 시퀀스 내에서 최대 10개의 테스트 자세에 대한 결과를 캡처하고 검토할 수 있는 기능을 사용자에게 제공해야 한다. |
| FR-04-04 | mandatory | 다자세 시퀀스 디스플레이는 최소한 CH, CB, 6H, 9H, 3H, 12H 자세에 대한 지원을 사용자에게 제공해야 한다. |
| FR-04-05 | mandatory | 다자세 시퀀스 디스플레이는 각 측정 자세에 대한 일오차(rate), 진각(amplitude), 비트 에러(beat error)를 사용자에게 제공해야 한다. |
| FR-04-06 | mandatory | 다자세 시퀀스 디스플레이는 모든 유효한 측정 자세의 평균값인 X를 사용자에게 제공해야 한다. |
| FR-04-07 | mandatory | 다자세 시퀀스 디스플레이는 가장 큰 측정값과 가장 작은 측정값의 차이인 D를 사용자에게 제공해야 한다. |
| FR-04-08 | desired | 다자세 시퀀스 디스플레이는 수직 자세와 수평 자세 간의 비교 기능을 사용자에게 제공해야 한다. |
| FR-04-09 | desired | 다자세 시퀀스 디스플레이는 밸런스 휠(balance-wheel)의 불균형 가능성을 파악하는 데 유용한 표시기(indicator)를 사용자에게 제공해야 한다. |
 
### G05 · Beat-Noise Scope Display
| ID | Grade | Requirement |
|----|-------|-------------|
| FR-05-01 | mandatory | 비트 노이즈 스코프 디스플레이는 프로그램을 재시작하지 않고 표시할 수 있도록 탭 형식 그래프 패널에 '비트 노이즈 스코프' 탭을 사용자에게 제공해야 한다. |
| FR-05-02 | mandatory | 비트 노이즈 스코프 디스플레이는 서로 연관된 두 개의 뷰인 '스코프 1'과 '스코프 2'를 사용자에게 제공해야 한다. |
| FR-05-03 | mandatory | 비트 노이즈 스코프 디스플레이는 데이터 손실 없이 캡처된 데이터를 일시정지하고 앞뒤로 탐색할 수 있는 기능을 포함하여 라이브(Live), 재생(Playback), 시뮬레이션(Sim) 모드를 사용자에게 제공해야 한다. |
| FR-05-04 | mandatory | 스코프 1은 시계에서 번갈아 발생하는 틱/톡(tick/tock) 비트 소리의 파형 표시 기능을 사용자에게 제공해야 한다. |
| FR-05-05 | mandatory | 스코프 1은 20 ms, 200 ms, 400 ms의 선택 가능한 시간 범위를 사용자에게 제공해야 한다. |
| FR-05-06 | mandatory | 스코프 1은 충분한 측정 시간이 경과한 후 현재 파형 아래에 작은 스트립 형태로 가장 최근의 비트 소리들을 사용자에게 제공해야 한다. |
| FR-05-07 | mandatory | 스코프 1은 확대 보기를 위해 누적된 이전 비트 스트립 중 하나를 선택할 수 있는 기능을 사용자에게 제공해야 한다. |
| FR-05-08 | mandatory | 스코프 1은 시인성 향상을 위해 신호를 절대값(\|x\|)으로 표시하는 옵션을 사용자에게 제공해야 한다. |
| FR-05-09 | mandatory | 스코프 1은 관련 A 및 C 비트의 식별 기능과 C 비트에 대한 시각적 마커를 사용자에게 제공해야 한다. |
| FR-05-10 | mandatory | 스코프 1은 화면에 표시된 비트 패턴과 관련된 구동각(lift angle)을 사용자에게 제공해야 한다. |
| FR-05-11 | mandatory | 스코프 2는 두 개의 수평 축에 표시되는 틱(tic) 및 택(tac) 비트 소리를 사용자에게 제공해야 한다. |
| FR-05-12 | mandatory | 스코프 2는 고정된 20 ms 시간 범위를 사용자에게 제공해야 한다. |
| FR-05-13 | mandatory | 스코프 2는 Σ 컨트롤을 통해 평균화 토글(켜기/끄기) 기능을 사용자에게 제공해야 한다. |
| FR-05-14 | mandatory | 스코프 2는 평균화가 켜져 있을 때 무작위 노이즈를 줄이고 신호의 명확성을 높인 결합된 비트 소리를 사용자에게 제공해야 한다. |
| FR-05-15 | mandatory | 스코프 2는 시계의 진동수(beat number) 및 선택한 간격에 따라 결정되며, 50번의 틱 간격과 50번의 택 간격 후에 완료되는 측정 사이클을 사용자에게 제공해야 한다. |
| FR-05-16 | mandatory | 스코프 2는 사이클이 끝날 때 화살표를 사용하여 각 수평 축에 평균 진폭을 사용자에게 제공해야 한다. |
| FR-05-17 | mandatory | 스코프 2는 고정된 tic/tac 축 할당을 가정하지 않고 평균화된 두 개의 비트 노이즈 트레이스를 사용자에게 제공해야 한다. |
| FR-05-18 | mandatory | 스코프 2는 10회 또는 20회 간격 측정 후와 같은 중간 평균화 결과를 사용자에게 제공해야 한다. |
 
### G06 · Beat Error Display and Diagnostic Trace
| ID | Grade | Requirement |
|----|-------|-------------|
| FR-06-01 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 일오차(rate), 진각(amplitude), 비트 에러(beat error), BPH(시간당 진동수) 값을 숫자와 단위와 함께 사용자에게 제공해야 한다. |
| FR-06-02 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 시계의 시간 동작 특성을 나타내는 틱/톡 트레이스 라인을 사용자에게 제공해야 한다. |
| FR-06-03 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 측정값(일오차, 진각, 비트 에러, BPH)과 틱/톡 트레이스 라인을 동시에 사용자에게 제공해야 한다. |
| FR-06-04 | optional | 비트 에러 디스플레이 및 진단 트레이는 시각적으로 구분되는 요소로서의 틱 트레이스 라인과 톡 트레이스 라인을 사용자에게 제공해야 한다. |
| FR-06-05 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 틱/톡 트레이스 라인 사이의 간격을 사용자에게 제공해야 한다. |
| FR-06-06 | optional | 비트 에러 디스플레이 및 진단 트레이스는 트레이스 라인 간격의 허용 범위를 구성할 수 있는 기능을 사용자에게 제공해야 한다. |
| FR-06-07 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 트레이스 라인 간격에 대해 정의된 허용 범위를 사용자에게 제공해야 한다. |
| FR-06-08 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 트레이스 라인 간격이 허용 범위를 초과할 때 사용자에게 경고를 제공해야 한다. |
| FR-06-09 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 트레이스 라인의 기울기를 사용자에게 제공해야 한다. |
| FR-06-10 | mandatory | 비트 에러 디스플레이 및 진단 트레이스는 트레이스 라인의 기울기가 45도 이상에 도달할 때 결함 상태 표시(fault-state indication)를 사용자에게 제공해야 한다. |

### G08 · Escapement Analyzer and Marker-Line Display

|----|-------|-------------|

| FR-12-03 | mandatory | 다중 필터 뷰가 포함된 스코프 기능은 측정이 획득되고 처리됨에 따라 모든 필터 뷰의 실시간 업데이트를 사용자에게 제공해야 한다. |
| FR-12-04 | mandatory | 다중 필터 뷰가 포함된 스코프 기능은 동일한 입력 신호 데이터와 동일한 시간축에서 렌더링된 모든 필터 뷰를 사용자에게 제공해야 한다. |
| FR-12-05 | mandatory | F0는 캡처된 신호를 화면에 맞게 포맷하고 평균값에 대해 대칭으로 대칭 복사(mirror)하여 제공해야 하며, 가공되지 않은 원래 시계 신호(raw watch signal)에 가장 가까운 표현으로 취급된다. |

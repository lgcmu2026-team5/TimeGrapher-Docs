# LG-CMU Software Architecture Course 2026 - Team 5
## Milestone 1: TimeGrapher Reference Architecture

이 문서는 LG-CMU Software Architecture Course 2026 과정의 **5팀(Team 5) Milestone 1** 결과물 인덱스 페이지입니다. TimeGrapher Reference Architecture 설계를 위한 문서 링크 및 요약은 다음과 같습니다.

---

### 📂 문서 인덱스 (Documentation Index)

1. **[Milestone 1-1: Project Plan](Milestone1_1-Project-Plan.md)**
   - 프로젝트 일정 관리, 작업 할당(Task Allocation) 및 개발 마일스톤 계획

2. **[Milestone 1-2: Architectural Drivers](Milestone1_2-Architectural-Drivers.md)**
   - 기능 요구사항(Functional Requirements), 품질 속성 시나리오(Quality Attribute Scenarios, QAS) 및 아키텍처 제약 사항(Constraints) 정의

3. **[Milestone 1-3: Risk Assessment](Milestone1_3-Risk-Assessment.md)**
   - 기술적 리스크 식별, 위험도 평가 및 이에 대응하는 아키텍처적 완화 방안(Mitigation Plan)

4. **[Milestone 1-4: Planned Experiments](Milestone1_4-Planned-Experiments)**
   - 아키텍처 결정을 검증하기 위한 프로토타이핑 및 모델링 실험 계획

5. **[Milestone 1-5: Architectural Approaches](Milestone1_5-Architectural%20Approaches)**
   - 아키텍처 목표를 달성하기 위해 선정한 설계 아키텍처 전술(Tactics), 패턴(Patterns) 및 구조적 접근법

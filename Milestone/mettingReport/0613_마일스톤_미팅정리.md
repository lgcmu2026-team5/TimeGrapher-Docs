## 1. 공통 사항 (전체 적용)

### 🔴 높음

**컬러 팔레트 통일**
모든 색상은 공통 컬러 팔레트에서 가져다 사용. 하드코딩된 색상값 제거하고, 다크/라이트 테마별 명도 차이가 반영된 팔레트 참조로 전환할 것.

**Position 선택 UI를 그래프 바깥으로 분리**
현재 각 탭 안에 포지션 선택이 있으나, 이를 공통 영역(좌측 패널 등)으로 빼서 전체 그래프에 일괄 적용되도록 변경. 포지션 변경 시 그래프 초기화/재그리기 정책도 공통 적용.

### 🟡 중간

**폰트 사이즈 공통 지정**
그래프 내 텍스트(축 라벨, 레전드 등)의 최소 폰트 사이즈를 공통으로 정의. 현재 그래프마다 글자 크기가 들쭉날쭉. Color Palette와 같은 공통 UI Config에 글자 폰트(작은/큰) 규격도 정의할 것.

**X축 눈금 / 레전드 표기 통일**
일부 그래프에 X축 눈금이 빠져 있거나, 축 단위(초/카운트 등)가 명시되지 않은 상태. 세로축 인덱스 자릿수에 따른 정렬 불일치(Long-term, Trace 등)도 고정 필요.

**Zoom In/Out 동작 통일**
Ctrl+휠, Shift+휠 등 줌 조작이 그래프마다 다르게 적용됨. 연관 그래프 간 X축 동기화도 확인 필요(Long-term 3개 그래프, Filter 4개 그래프 등).

### 🔵 낮음

**다크모드 시인성 리뷰** — 구현 완료 후 접근성 시인성 리뷰 수행 예정. 색약 모드(초록→파랑 대체) 고려. 바 모양(굵기, 점선 등) 차별화도 병행.

**Help 버튼 추가** — 테마 버튼 좌측에 물음표(?) 버튼을 만들어 가이드 문서(Glossary 등)를 연결. 프로그램 내부가 아닌 별도 HTML/문서로 열리게 구현.

### ✅ 결정사항

- Stop 버튼 → **Reset 버튼으로 변경**. Play 중에는 Reset 불가, Pause 상태에서만 Reset 활성화.
- 색상은 모두 **컬러 팔레트에서 가져다 사용**. 하드코딩 금지.
- **용어 통일**: error rate / daily rate / rate deviation → **"Error Rate"**로 통일. bit error는 **"Bit Error"**로 통일. amplitude(시계 각도) vs signal amplitude(신호 세기)는 구분하여 사용 (신호 쪽은 magnitude 또는 intensity 등 별도 용어 채택 검토).

## 2. QAS 실험 조건 정리

### 🔴 실험 조건 재정비 및 추가 실험

- 기본 조건: 125ms (기본) / 83ms (192kHz 스트레치 목표)
- 제공된 샘플 중 384kHz 데이터가 있었으나 Quality Attribute 스펙은 192kHz 기준
- 384kHz는 "샘플 데이터에 있어서 돌려본 결과 문제 없었음" 정도로 별도 기재
- 정식 실험은 스펙 기준(192kHz)으로 재수행

> ✅ **결정**: 실험 조건을 Quality Attribute 스펙에 맞추어 재실험. 432BPH / 384kHz 조건은 추가 행으로 별도 기재.
>
> ✅ **결정**: Quality Attribute 내 FR 관련 항목 → 삭제 (관리 어려움).

### 🟡 장시간 에이징 테스트

14시간 시뮬레이션 예정. 마이크 입력 vs 시뮬레이션 차이 확인 후 결정. `top` 명령으로 프로세스/메모리 점유율 주기적 모니터링. 금일 밤~내일 밤 실행 예정.

## 3. 아키텍처 / 디자인 패턴 스터디

### 🟡 MVC 패턴 / 더블 버퍼링 / 레이어 구조 정리

현재 코드에 MVC 패턴, 더블 버퍼링이 적용되어 있음을 확인. C++→C# 전환 과정에서 일시적 다운그레이드(싱글 버퍼 등) 후 복원된 이력 존재.

**정리 방향:** "MVC 패턴을 채택했고, 더블 버퍼링을 유지하기로 결정했다"는 식으로. 이전 대비 성능 개선이 아닌 "성능 유지/안정화를 위해 채택" 관점으로 서술. 스터디 기록 형식으로 문서화.

### 🟣 Pub/Sub vs Observer 패턴 — 논의 필요

데이터 버스에 넣고 필요할 때 가져가는 구조 → Pub/Sub 또는 Observer로 볼 수 있으나 명확하지 않음. 멘토 시간에 확인 예정. 명확한 패턴만 문서에 기재.

> ⚡ **액션**: 스터디 결과 문서 마일스톤 종료 전(목요일)까지 정리. 블록도 기반 분석 내용 포함.

## 8. 준영 책임님 — Spectrum, Filter Scope, Sweep

### Spectrum / Spectrogram

| 우선순위 | 항목 | 설명 |
|---------|------|------|
| 🔴 높음 | Grid 색칠 (배경 안 보이게) | 현재 라인으로만 그려져 있어 검은 배경이 비침. 픽셀 단위로 색칠(fill)하여 상용 제품처럼 빈틈 없이 표현해야 함. 윈도잉(windowing) 처리 후 FFT → 겹쳐서(overlap) 보여주는 방식으로 변경 필요. |
| 🟡 중간 | 미구현 버튼들 완성 | 사용자 옵션에 따른 기능(주기별 갱신, 윈도우 크기 설정 등)이 아직 구현되지 않은 상태. |
| 🔵 낮음 | 색상 범위 / 테마 적용 | 끝단이 어두운 색이라 구분 안 됨. 데시벨 색상 매핑 조정 필요. 다크/라이트 테마 전환도 미적용. |

### Filter Scope (G08)

| 우선순위 | 항목 | 설명 |
|---------|------|------|
| 🔴 높음 | Signal Flow 변경 — F0이 Raw Signal 직접 수신 | 현재: 마이크 입력 → 하이패스 필터 → 인벨로프 → 데이터 전달. **변경: F0(캡처 신호)는 원본(raw) 시그널을 바로 받아야 함.** 블록도 수정 및 시그널 플로우 재설계 필요. |
| 🟡 중간 | 4개 그래프 X축 동기화 | Zoom In/Out 시 F0~F3 네 그래프의 X축을 맞추는 것이 바람직. |

### Sweep (G10, G11)

| 우선순위 | 항목 | 설명 |
|---------|------|------|
| 🟡 중간 | 틱/톡 파형 위치 오류 수정 | 현재 틱/톡이 잘못된 위치에 표시됨. 타이밍 마커(빨간/초록 선)와 비교 기능 정상 동작 확인 필요. |
| 🟡 중간 | 배율 버튼(1x/2x/4x) 기준 수정 | 현재 "틱 간격"으로 구현되어 있으나, 정확히는 "틱~킥(tick) 간격의 배수"여야 함. |
| 🔵 낮음 | 파형 오버레이 비교 기능 | 연속적인 비트 파형을 겹쳐서(오버레이) 보여주는 기능 — FR 권장사항. 다른 색/투명도로 겹쳐 변화 시각화. |
| 🔵 낮음 | 표시 개수 조절 (2/4/8개) | 현재 8개 고정 → 2/4/8개 선택 버튼 추가. 큰 화면으로 비교 용이하게. |

## 9. 재생 제어 (Play/Pause/Reset) 정책

> ✅ Stop 버튼 폐지 → **Reset 버튼으로 대체**
>
> ✅ Play 중에는 **Pause만 가능**. Pause 상태에서만 Reset 활성화.
>
> ✅ Reset 시 모든 그래프 데이터 초기화(플러싱). 데이터 삭제 시점을 Stop→Play 시작 시가 아니라, **Reset 시점**으로 변경.
>
> ✅ Pause 상태에서 다른 탭/그래프 선택 시 **측정된 데이터 유지**되어야 함 (현재 Stop 시 날아감 → 수정).

## 1. 마일스톤 1 실험 계획 진행 현황

- 실험 계획 5개 항목 중 3~4개 완료, 일부 미완료 항목 존재
- **C# 선택 리서치:** C#으로 프로젝트 진행하기로 결정했으나, 문서상에 선택 이유가 명확히 기술되지 않았다는 피드백 있음. 구두 설명은 했으나 문서 보완 필요
- **소프트웨어 성능 실험 결과:**
  - 예산 84ms 기준 3ms 컷팅 문제 없음
  - 시뮬레이션 플레이/라이브: 43,200HP, HPFS 40% 수준 → 완료 판정
  - **24시간 안정성 테스트:** CPU 사용률 피크 ~150%, 메모리 사용률 피크 440MB로 평탄 유지
- **CPU 사용률 표기 관련:** 멀티코어 환경에서 400% 표기 대신 **100% 기준으로 스케일링**하기로 합의 (리눅스/윈도우 차이 고려)

## 2. TinyML 및 리스크 관리 전략

- TinyML 관련 실험은 옵셔널 기능이나, 리스크를 "High"로 잡아둔 상태
- 실험 자체는 어느 정도 완료되었으나 최종 확정(도장)을 찍지 않은 상태로 "진행 중" 표기
- **마일스톤 2 대비 전략:** "왜 리스크 항목을 끝내지 않고 개발을 진행하느냐"는 질문이 예상됨. GUI 개발과 성능 실험을 레이어 분리하여 병렬 진행 중이라는 점을 설명하기로 함
- Arcatics Tactic 관련 내용 중 명확히 설명 가능한 항목 1~2개를 뽑아 문서 정리 필요

## 3. 전체 공통 결정사항

### 3-1. Zoom-in/out 정책
- **최대한 불필요한 줌 기능은 제거**
- 줌이 꼭 필요한 경우에만 **+/- 버튼**으로 구현 (가로축/세로축/전체 중 선택)
- 마우스 휠: +버튼 = Wheel Up, -버튼 = Wheel Down으로 대응
- **키보드 조합:** Shift = 세로 줌, Ctrl = 가로 줌
- 터치스크린에서도 동일 기능이 가능해야 함 (마우스로 되는 일은 터치로도 가능해야 함)
- 멀티터치(핀치 줌) 미지원 확정 → 리스크 회피
- 그래프별 최소/최대 줌 범위를 각 담당자가 검토

### 3-2. 용어 통일
| 기존 용어 | 변경 후 | 비고 |
|---|---|---|
| Amplitude (시계 pallet fork 각도) | **Amplitude** (단위: 도°) | 기존 유지, 단위 명시 |
| Amplitude (신호 크기) | **Signal Level** | 혼동 방지용 변경 |
| Rate / Error Rate | **Error Rate** (문서 기준 확인 후 확정) | Bit Error와 짝 맞춤 |

- 용어 정리는 한 명이 주도적으로 잡아서 전체 통일하기로 함

### 3-3. 색깔 정책
- 경쟁사 참고: 빨/파/초(RGB 계열) 사용
- 색맹/색약 접근성 고려 필요 → GPT 등 AI에 accessibility 기준 시안 요청 가능
- 한 명이 총괄하여 색깔 정책 수립 예정

### 3-4. 그래프 하단 서술형 설명
- 매뉴얼에 동일 내용이 있으므로 **그래프 내 서술형 텍스트 제거**
- 사용자는 매뉴얼 참조하는 것을 기본 전제로 함

### 3-5. 경쟁사 비교
- 경쟁사 제품(위시스 등)과 화면 구성 비교 계속 진행
- 기능보다는 **어떤 데이터를 중점적으로 보여주느냐** 관점에서 참고

### 3-6. 터치스크린 리스크
- 터치스크린 테스트를 실험 항목에 추가
- 핀치 줌 미지원, 멀티터치 미지원 확정
- 클릭(원포인터 터치) + 드래그(스와이프)만 지원
- 라즈베리파이 환경에서 마우스/키보드 연결 여부에 대해 파이썬 담당자와 추가 논의 예정

### 3-7. 기타 공통
- **Help 버튼** 추가: 매뉴얼 브라우저 연동 (물음표 아이콘)
- **Settings** 진입: 톱니바퀴 아이콘으로 테마 옆에 배치 (탭 추가 방식은 부적합)
- **매일 새벽 3시** 자동 코드 리뷰(최근 24시간 커밋) → 자동 수정 후 푸시
- 우선순위(High/Mid) 및 문서 정비, 버전 릴리즈는 GitHub Releases 기준

## 4. 담당자별 작업 내역 및 할 일

### 성준 책임
**완료/진행 중:**
- 그래프 시뮬레이션 시간 표시, 채널 전환 시 동기화 처리
- Long-term 뷰: 전체 구간 내 현재 위치 표시 바 추가, 위치 조정
- 플레이백 리뷰 바 UI 개선

**할 일:**
- UI 잔여 수정 (빈 공간 처리, 커서 데이터 표시 등)
- 시간 인덱스 표기 정리 (밀리세컨드 불규칙 → 깔끔한 간격으로)
- 그래프 초기 표시: X축 눈금 **5개** 정도로 제한
- Long-term과 Trace 차이점을 경쟁사 참고하며 반영
- 마이크 연결 해제 시 에러 처리 개선 (input device 자동 갱신, 사용자 친화적 에러 메시지)

### 준성 책임
**완료/진행 중:**
- Rate Scope, Sound Print 등 기본 기능 구현
- 점 크기 조절, 비트 에러/비트 노이즈 그래프 작업

**할 일:**
- **그래프 해상도 문제 수정:** 30초 뷰에서 8,000포인트 압축으로 coarse해진 문제 → **2초 뷰로 복원** (또는 30초 시 20,000포인트로 확대)
- 점 크기 키우기 (확대해도 점이 안 커지는 문제 → 일정 크기 유지 or 약간 확대)
- 에러 시나리오별 테스트 WAV 파일 제작 및 검증
- 빨간색 마커(A/C 포인트) 표시 오류 확인
- 폰트 사이즈 확대 (하이패스 컷오프 등 텍스트)

### 종대 책임
**할 일:**
- **비트 노이즈 그래프 구간 분할 수정:** 현재 Tick→Tock 간격으로 나뉘는 것을 **Tick→Tick 간격**으로 변경
- 빨간색 마커 2개가 찍히는 현상 원인 파악 (노이즈 관련 정보인지, 버그인지 확인 후 조치)
- Waveforms/Sweep 그래프의 Tick-Tock 기준점 일치 확인

### 재홍 책임
**할 일:**
- **Long-term 그래프 vs Trace 그래프 차이점 검토** (요구사항 문서 기반)
- 비전 스터디 정리 (이번 주 내)

### 준영 책임
**완료/진행 중:**
- 스펙트로그램 UI 개선 (배경색 구분, 줌인/줌아웃 시 초기화 방지)
- 오실로스코프 실시간 동기화
- Reset Bit 위치 계산 → 가운데 출력 안정화
- 빨간색 현재 갱신 위치 표시선 추가
- 필터 3종(원본, F0, F1) 동작 확인

**할 일:**
- **그래프 coarse 문제:** 준성 책임과 동일 원인 (30초 압축) → **2초 뷰로 수정**
- 스펙트로그램 확대 시 데이터 소실 문제 해결
- 코드 업로드 및 정리

### 선영님
**할 일:**
- **Waveforms Y축:** Current → Past 방향으로 표기 변경 (최신=위, 과거=아래)
- **Waveforms X축:** "Tic | Toc" 텍스트 대신 **색상 표기**(초록=Tic, 빨강=Toc)
- **Sweep 그래프:** Rate, Amplitude, Beat Error 항목 정리
- Waveforms와 Sweep 그래프 간 **Tic/Toc 기준점 일치** 작업
- 1x↔3x 전환 시 왼쪽 빈 영역 채우기 (이전 데이터 유지)
